## 1. Architecture & Core Foundations

- [ ] **Dual-Loop Worker Resilience**: Keep Textual UI on thread 1 and Telethon on thread 2. Auto-reconnect worker with exponential backoff on network dropouts.

- [ ] **Unified Event Bus**: Coalesce high-frequency events (e.g. fast-scrolling channels) to 30 Hz max refresh to guarantee zero typing latency.

- [ ] **Strict Memory Cap**: Strict LRU memory pruning for message cache (keep &lt;= 300 messages per inactive chat in RAM, stream older from SQLite WAL).

- [ ] **Non-Blocking Background Tasks**: File downloads, uploads, and AI transcriptions execute via worker thread pool; UI status bar receives percentage updates without any frame drops.

## 2. Authentication, Accounts & Sessions

- [x] **Terminal ASCII QR Code Login (**`Q`**)**:

  - Render terminal QR code via UTF-8 block characters (`▄▀█`).
  - Listen for Telegram mobile app scan; auto-authenticates without typing phone number or SMS code.
  - Auto-refreshing QR token with countdown progress bar.

- [x] **Instant Account Switcher**:

  - Fast-switch via number keys `1`–`9` or `F2` / `Shift+F2`.
  - Global badge showing unread count per account on the account strip (e.g. `[1: @alice (3)] [2: @work]`).

- [x] **MTProto / SOCKS5 / HTTP Proxy Support**:

  - Configure proxies in `config.json` with live latency probe (`[proxy: 42ms]`).
  - Quick toggle proxy on/off from Command Palette (`Ctrl+K` -&gt; `Toggle Proxy`).

- [x] **Active Sessions Manager Screen**:

  - Inspect all active Telegram sessions across phones, desktops, and web.
  - One-key revocation (`d`) of suspicious or old sessions.

- [x] **User Profile & Status Management**:

  - View profile bio, username, and online status.
  - Set custom Telegram status emoji or bio directly from terminal.

## 3. Chat List, Folders & Dialog Triage

- [ ] **Bidirectional Cloud Folder Sync**:

  - Full sync of Telegram cloud folders (Personal, Work, News, etc.).
  - Create, rename, reorder, or delete folders directly in `tg-cli`.

- [ ] **Synthetic Smart Filter Tabs**:

  - `All`: All chats.
  - `Unread`: Only chats with unread messages or mentions.
  - `Direct`: 1-on-1 private conversations.
  - `Groups`: Supergroups and basic groups.
  - `Channels`: Broadcast channels.
  - `Bots`: Bot conversations.

- [ ] **Quick Jump Hotkeys**:

  - `gs`: Jump directly to personal **Saved Messages**.
  - `ga`: Jump directly to **Archive**.
  - `gu`: Jump to next unread chat.
  - `gm`: Jump to next chat with an unread `@mention` or reply.

- [ ] **Local Tags & Notes**:

  - Tag chats with private local tags (e.g. `#lead`, `#vip`, `#urgent`, `#mute-until-monday`).
  - Filter list by local tag (`/#vip`).

- [ ] **Pinned Chat Reordering**:

  - Reorder pinned chats up/down using `Shift+J` / `Shift+K`.

- [ ] **Folder-Level Bulk Operations**:

  - `Shift+M`: Mute all chats in current folder.
  - `Shift+R`: Mark all chats in current folder as read (with confirmation).
  - Clean inactive chats (&gt;60 days inactive) to archive in one command.

## 4. Message Reading, Viewport & Rich Rendering

- [ ] **Adaptive Dual-Pane / Split-Pane View**:

  - On wide terminals (&gt;= 120 columns), show Chat List on left (\~34 cols) and Message Stream on right.
  - Single-key toggle between panes (`Ctrl+W` or `Alt+Left`/`Alt+Right`).
  - Seamless fallback to stacked single-pane on smaller terminals.

- [ ] **Forum Topics & Threads Support**:

  - Full support for Telegram Supergroups with Topics/Forums enabled.
  - Topic picker sidebar / sub-list (`Enter` on forum supergroup lists topics with unread indicators).

- [ ] **Rich Code Syntax Highlighting**:

  - Render code snippets (e.g. `python ... `) with Textual / Rich syntax highlighting.
  - Single key `y` to copy entire code block to clipboard.

- [ ] **Polls & Interactive Voting**:

  - Compact rendering of polls with vote distribution bars (`█████░░░ 62%`).
  - Press `1`–`9` to cast or retract vote in poll.

- [ ] **Webpage Preview Cards**:

  - Compact 2-line preview card for links containing page title, site name, and summary description.

- [ ] **Jump to Message ID / Timestamp**:

  - Command input `:#<msg_id>` or `:14:30` to jump directly to specific points in history.

- [ ] **Live Edit Diffs**:

  - Subtle visual flash when focused message is edited by sender in real-time.

## 5. Message Composition, Formatting & Scheduling

- [ ] **Keyboard Formatting Shortcuts**:

  - `Ctrl+B`: Bold (`**text**`)
  - `Ctrl+I`: Italic (`__text__`)
  - `Ctrl+K`: Inline Markdown link (`[text](url)`)
  - `Ctrl+` ``` : Inline code (`` ```code\` \`\`)
  - `Ctrl+Shift+S`: Spoiler (`||spoiler||`)
  - `Ctrl+Shift+X`: Strikethrough (`~~text~~`)

- [ ] **Vim Mode for Composer**:

  - Optional modal editing inside the message box (`Esc` for normal mode, `i`/`a` for insert, `w`/`b` word motion, `dd` clear line).

- [ ] **Readline Keybindings**:

  - Support standard terminal editing keys: `Ctrl+A` (start of line), `Ctrl+E` (end), `Ctrl+U` (clear to start), `Ctrl+W` (delete backward word).

- [ ] **Scheduled Messages (**`:schedule`**)**:

  - `:schedule 30m` or `:schedule 2026-10-06 09:00` or `:when-online`.
  - View and cancel scheduled messages queue for the chat.

- [ ] **Emoji Shortcodes & Autocomplete**:

  - Type `:thumb` or `:fire` to open a 5-item inline popup picker and insert Unicode emoji.

- [ ] **Cloud Drafts Synchronization**:

  - Bidirectional sync with Telegram Cloud Drafts (typing on phone reflects in CLI, and vice versa).

## 6. Message Actions, Reactions & Interactions

- [ ] **Message Forwarding (**`f`**)**:

  - Press `f` on focused message (or multi-selected messages `v`/`Space`).
  - Search destination chat via fuzzy popup.
  - Toggle `c`: Forward with or without original author attribution ("hide sender name").

- [ ] **Quick Emoji Reactions (**`x`**)**:

  - Press `x` to show 6 quick reactions (`1: 👍`, `2: ❤️`, `3: 🔥`, `4: 😂`, `5: 👏`, `6: 😢`) or custom emoji input.
  - Reactions summary pill displayed compactly under message (`[👍 4] [❤️ 2]`).

- [ ] **Pin / Unpin Messages (**`p`**)**:

  - Pin message in chat or group (with toggle for quiet pin).
  - Persistent pinned message banner at top of chat; press `P` to jump directly to it.

- [ ] **Star / Bookmark to Saved Messages (**`s`**)**:

  - Quick-save important messages into personal Saved Messages in a single keypress.

- [ ] **Mark as Unread From Here**:

  - Mark chat unread starting from the currently focused historical message.

- [ ] **Extended Copy Options (**`y`**)**:

  - `y`: Copy plain text.
  - `Y`: Copy message permanent link (`t.me/c/...`).
  - `Ctrl+Y`: Copy formatted markdown.

- [ ] **Delete for Everyone Confirmation**:

  - `d`: Delete for me (undoable 5s).
  - `Shift+D`: Delete for everyone (prompts modal `y/n` confirmation).

## 7. Media, Files, Audio & AI Voice

- [ ] **Send Local Files & Documents (**`Ctrl+O` **or** `:file`**)**:

  - Prompt local file path with autocompletion / interactive terminal file browser.
  - Upload progress bar on status line (`Uploading document.pdf: [████░░] 67%`).
  - Confirmation prompt for files &gt; 50 MB.

- [ ] **External Media Opener (**`o` **/** `Enter` **on media)**:

  - Press `o` on `[photo]`, `[video]`, `[file]`, or links:
    - URLs open in default web browser.
    - Media files download to cache and open in Windows default viewer via `os.startfile`.

- [ ] **Terminal In-Band Image Rendering (Optional)**:

  - Render low-res preview of photos directly inside terminal using Kitty graphics protocol, Sixel, or Unicode half-blocks (`chafa`).
  - Configurable toggle (`image_preview: "unicode" | "none"`).

- [ ] **Voice Note Recording**:

  - Press `Ctrl+R` to record voice message from default Windows microphone.
  - Real-time duration timer; press `Enter` to send or `Esc` to discard.

- [ ] **Local Voice & Audio Playback**:

  - Play voice notes or audio attachments directly through system speaker with `Space` (pause/play) and progress indicator.

- [ ] **Multi-Provider AI Voice Transcription**:

  - Expand beyond Google Gemini to include:
    - Local offline Whisper (`whisper.cpp` / `faster-whisper` — zero network latency, full privacy).
    - OpenAI Whisper API.
    - Groq Whisper (sub-second cloud transcription).
  - Auto-transcribe incoming voice messages toggle in `config.json`.

## 8. Search, Discovery & History Navigation

- [ ] **Global Cross-Chat Search (**`Ctrl+Shift+F` **or** `g/`**)**:

  - Search all accessible dialogs via Telegram `messages.searchGlobal`.
  - Results view showing chat title, message snippet, sender, and date.
  - Pressing `Enter` opens chat and focuses the exact historical message.

- [ ] **Calendar / Date Jumper (**`gd` **or** `:date`**)**:

  - Jump directly to messages around a date (`:date 2026-05-15`).

- [ ] **Chat Media Filter View**:

  - Filter chat history by media type: `/photos`, `/files`, `/links`, `/voice`, `/pinned`.

- [ ] **Public Username & Channel Search**:

  - Search public channels/bots by `@handle` without joining.
  - View preview history and option to join (`J`).

  - Notification displays sender name, chat title, and message snippet.

- [ ] **System Tray Companion (Optional Daemon)**:

  - Run `tg-cli --daemon` in Windows System Tray.
  - Global hotkey (e.g. `Win+Alt+T`) to bring terminal window to focus.

  - `compact` mode (1 line per chat, dense messages) vs `cozy` mode (subtle margins).

## 12. Offline Mode, Data Export & Database Maintenance

- [ ] **Complete Offline Browsing**:

  - Full read-only access to cached chats, messages, drafts, and transcripts when internet is unavailable.
  - Offline send queue: Outgoing messages automatically queue and send when connection is restored.

- [ ] **Chat History Export (**`:export`**)**:

  - Export chat history to Plain Text, Markdown, or JSON (`:export markdown D:\notes\chat.md`).

- [ ] **Database Maintenance Utility (**`:vacuum`**)**:

  - Prune old cached messages (&gt;90 days), wipe temporary downloaded media, optimize SQLite WAL file.

## 13. CLI Automation, Scripting & IPC

- [ ] **Headless Pipe & Send Command**:

  - Send message directly from PowerShell / cmd without entering full UI:

    ```powershell
    tg-cli send --to "@alice" --text "Build completed successfully"
    # Or via pipe:
    Get-Content log.txt | tg-cli send --to "DevOps Alerts"
    ```

- [ ] **Local Named Pipe / IPC API**:

  - Lightweight localhost IPC server allowing local scripts or GitHub Actions / webhooks to trigger notifications in `tg-cli`.
